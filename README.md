## 📌 Описание задания

Создать веб-сервер в Docker с использованием Nginx и подключить HTML-страницу.  
Результат доступен по адресу <http://localhost:3000> (в начале работы использовался порт 8080, затем изменён на 3000).

---

## ⚙️ Как запустить проект

1. Клонировать репозиторий:

```
git clone <ссылка на репозиторий>
cd nginx-lab
```

2. Запустить контейнеры:

```
docker-compose up -d --build
```

3. Открыть в браузере: `http://localhost:3000`
   (страница «О проекте»: `http://localhost:3000/about.html`)

4. Остановить:

```
docker-compose down
```

## 📂 Содержимое проекта

- `docker-compose.yml` — описание сервиса Nginx (образ `nginx:1.27-alpine`, порт `3000:80`, том `./code:/usr/share/nginx/html`)
- `code/index.html` — главная HTML-страница
- `code/about.html` — вторая страница

## 🧪 Ход работы

1. **Подготовка окружения.** Установлен Docker, версия проверена командами `docker --version` и `docker-compose --version`.
2. **Первый запуск Nginx.** Создан `docker-compose.yml` с образом `nginx:1.27-alpine` и портом `8080:80`. После `docker-compose up -d` по адресу `http://localhost:8080` открылась стандартная страница «Welcome to nginx!».
3. **Свой сайт.** Создана папка `code` с `index.html`, в `docker-compose.yml` добавлен том `./code:/usr/share/nginx/html`. После перезапуска (`docker-compose up -d --build`) сервер отдаёт собственную страницу.
4. **Эксперименты.**
   - Изменён текст в `index.html`: изменения видны сразу после обновления страницы, так как папка смонтирована как том и перезапуск контейнера не нужен.
   - Добавлен `about.html`, доступен по `http://localhost:8080/about.html`.
   - Порт `8080` заменён на `3000` (`"3000:80"`), после `docker-compose up -d` сайт доступен по `http://localhost:3000`.
